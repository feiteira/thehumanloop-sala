# Glosario

| Inglés | Portugués | Español | Qué es |
|---|---|---|---|
| Folder | Pasta | Carpeta | Todo lo relativo a un paciente. |
| Shelf | Estante | Estantería | Todas sus carpetas; el archivo guarda las cerradas. |
| Page | Página | Página | El registro de una sesión. |
| Sticky note | Nota adesiva | Nota adhesiva | Un recordatorio breve en una portada o en una página. |
| Peel off | Descolar | Despegar | Marcar una nota adhesiva como terminada. |
| Divider | Separador | Separador | Una sección de una carpeta: Páginas, Temas, Calendario, Documentos, Historial de notas. |
| Theme | Tema | Tema | Una o dos palabras que marca en fragmentos de sus notas, para seguirlo sesión a sesión. |
| Private process note | Nota de processo privada | Nota de proceso privada | Sus propias reflexiones, guardadas aparte del registro. |
| Passphrase | Frase-passe | Frase de acceso | Lo que escribe para abrir Sala. |
| Recovery phrase | Frase de recuperação | Frase de recuperación | 12 palabras que abren su consulta si olvida la frase de acceso. |
| Backup | Cópia de segurança | Copia de seguridad | Una copia cifrada de toda la consulta, en la carpeta que usted elija. |
