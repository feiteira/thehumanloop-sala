# Glossário

| English | Português | Español | O que é |
|---|---|---|---|
| Folder | Pasta | Carpeta | Tudo o que diz respeito a um paciente. |
| Shelf | Estante | Estantería | Todas as suas pastas; o arquivo guarda as que estão fechadas. |
| Page | Página | Página | O registo de uma sessão. |
| Sticky note | Nota adesiva | Nota adhesiva | Um lembrete curto numa capa ou numa página. |
| Peel off | Descolar | Despegar | Marcar uma nota adesiva como concluída. |
| Divider | Separador | Separador | Uma secção de uma pasta: Páginas, Temas, Calendário, Documentos, Histórico de notas. |
| Theme | Tema | Tema | Uma ou duas palavras que marca em excertos das suas notas, para o acompanhar sessão a sessão. |
| Private process note | Nota de processo privada | Nota de proceso privada | As suas reflexões pessoais, guardadas à parte do registo. |
| Passphrase | Frase-passe | Frase de acceso | O que escreve para abrir o Sala. |
| Recovery phrase | Frase de recuperação | Frase de recuperación | 12 palavras que abrem a sua prática se se esquecer da frase-passe. |
| Backup | Cópia de segurança | Copia de seguridad | Uma cópia cifrada de toda a prática, numa pasta à sua escolha. |
